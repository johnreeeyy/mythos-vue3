# Mythos Vue 3

An interactive mythology explorer built with Vue 3. This app lets users browse gods from Greek and Norse mythology, search and filter results, and view detailed information in a modal.

Favorites can be saved and are stored locally in the browser using localStorage.

## Features

- Search gods by name
- Filter by mythology (Greek / Norse / All)
- Favorites system to save preferred gods
- Persistent favorites using localStorage
- Dynamic modal view for detailed god information
- Responsive UI design with smooth interactions
- Built with modern Vue 3 Composition API

## What I Learned

This project helped reinforce and apply core frontend concepts such as:

- Vue 3 Composition API (ref, computed)
- Props and event emitting (defineProps, defineEmits)
- State management patterns (lifting state up)
- List rendering with v-for
- Conditional rendering (v-if)
- UI state handling (modals, filters, toggles)
- Event handling and propagation (@click, .stop)
